# フロントエンドエンジニアのためのフルスタック開発入門

書籍『フロントエンドエンジニアのためのフルスタック開発入門』のサンプルコードです。

記事の投稿と閲覧ができる小さなブログサービス「mini-blog」を、本のとおりに作り、AWS で動かして確かめたものです。本の第3部〜第5部で作るコードの、完成した形が入っています。

##  シーケンス図 

書籍に付属するシーケンス図です。学習の際、データの流れを確認しながら学ぶと分かりやすいので、ご活用ください。

- [mini-blog-diagrams-a4.pdf](docs/mini-blog-diagrams-a4.pdf)

## フォルダ構成

| フォルダ・ファイル | 中身 | 本の章 |
| --- | --- | --- |
| `backend/` | API（NestJS・Prisma） | 3-2、4-2 |
| `frontend/` | 画面（Next.js） | 3-3、4-2 |
| `compose.yaml` | 手元で動かす3つのコンテナ（DB・API・画面） | 3-2、4-3 |
| `infra/` | AWS のリソース（Terraform） | 4-1、5-1、5-3 |
| `infra/env/` | dev・prod の変数と state の置き場所 | 4-1、5-1、5-3 |
| `.github/workflows/` | 自動デプロイ（GitHub Actions） | 5-2、5-3 |

※書籍では、作業フォルダとリポジトリの名前を `mini-blog` にしています。このリポジトリは名前が違いますが、中身は同じです。

## 使うときの注意

- 書籍の手順に合わせて、少しずつ作りながら読むことをおすすめします。完成したコードは、つまずいたときに見比べるために使ってください。
- `infra/env/` の値（`example.com`、`you@example.com`、`OWNER@12345678`、`（アカウントID）`、`xxxx` など）は、例です。自分の値に置き換えてください（本の 4-1・5-1・5-2）。
- `.env` などの秘密を含むファイルは入っていません。本の 4-1-9・4-3 のとおりに作ってください。
- AWS の上で動かしている間は、料金がかかります（dev で1日 約 3 USD）。使い終わったら、本の 5-4 のとおりに削除してください。

## 確認したバージョン

Node.js 22、npm 11、NestJS 12、Prisma 7、Next.js 16、PostgreSQL 17、Terraform 1.11 以上（2026年10月時点）。詳しくは、本の B-6 にあります。
